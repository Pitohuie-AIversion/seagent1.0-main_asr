# 累计集成测试集（当前配置同步版）

> 可执行行为以 `tests/run_accumulation_integration_tests.py` 为准。
> 本文档用于人工复现和评审场景，不再维护与脚本不同的设备、坐标或时间基线。

## 执行基线

- 后端地址统一为 `http://localhost:8890`。
- 模拟时间固定为 `2026-07-10T18:10:00+08:00`，正常遥测时间为 `18:00`。
- TS-10 使用 `16:00` 作为明确过期的遥测时间。
- 无告警管缆基线使用 `(17.60,111.00)` 至 `(17.70,111.10)`，避开禁入区与 DVL 风险区。
- TS-02 使用徐闻珊瑚礁禁入区 `(20.40,109.85)` 至 `(20.45,109.90)`。
- 工作级 ROV 场景默认使用陵水17-2 `(17.52,110.15)`、井口 `B07`，避免 DVL 告警污染目标约束。

运行本文档中的独立命令前，先设置模拟时间：

```shell
curl -X POST http://localhost:8890/api/time/set -H "Content-Type: application/json" -d '{"time":"2026-07-10T18:10:00+08:00"}'
```

## 决策记录

- 当前 `config/environment.yaml` 与 `config/robot_fleet.yaml` 是坐标和装备名称的权威来源。
- 状态注入使用机器人清单中的 `status_ref`；任务消息仍使用面向调度的 `unit_id`。
- 每个约束用例只注入目标异常，其他遥测使用同一份正常基线。
- TS-18/TS-19 的复合任务请求在写入 Slot 前确定性阻断；TS-19 已移除历史 `expected_failure`，不得通过放宽断言掩盖回归。
- TS-28 对消息中逐字出现的 schema 枚举值进行确定性恢复，但不得接受 `allowed_values` 之外的值或覆盖已有模型候选。
- 当前 API 尚未返回结构化约束代码，因此现阶段仍匹配语义关键词；后续若增加 `violation_codes`，应优先改为结构化断言。

自动化脚本默认运行全部场景，也可用环境变量定向复验：

```shell
ACCUMULATION_TEST_IDS=TS-18,TS-19,TS-28 /root/miniconda3/envs/seagent/bin/python tests/run_accumulation_integration_tests.py
```
