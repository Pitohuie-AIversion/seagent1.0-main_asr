# Qwen3.5-9B 推理性能基准测试报告 (vLLM 0.95 最大显存配置)

> **测试目的**：评测 RTX 5090 (32GB) 在显存分配达 95% 极限利用率下的推理性能指标（时延、解码速率、并发吞吐量），供后续与专用加速芯片（如 HB10）进行横向性能对比。

## 1. 硬件与环境配置 (Hardware & Environment)

- **测试设备**: `NVIDIA GeForce RTX 5090` (显存总量: `32607.0 MB` / ~32GB)
- **显存占用分配设置**: `gpu_memory_utilization = 0.95`
- **实测显存占用水位**: `29682.0 MB` (91.0% 饱和)
- **模型权重**: `Qwen3.5-9B` (BF16, 物理路径 `/root/autodl-tmp/model/Qwen3.5-9B`)
- **推理引擎**: `vLLM 0.18.1` (Prefix Caching: 关闭以测纯算力, PagedAttention 启用)
- **CUDA / 驱动**: `CUDA 13.2` / `Driver 595.71.05`

## 2. 单请求基准时延测试 (Batch Size = 1 Latency)

主要用于衡量单个交互请求的端到端时延和解码流式生成速度。

| 业务场景 | 输入 Token | 输出 Token | 端到端总时延 (s) | TPOT (单Token延迟) | 解码生成速率 (Tokens/s) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 短文本交互 | 128 | 128 | 5.5288 s | **43.19 ms** | **23.15 tokens/s** |
| 标准对话/任务抽取 | 512 | 256 | 2.8002 s | **10.94 ms** | **91.42 tokens/s** |
| 长上下文对话 | 2048 | 512 | 5.6621 s | **11.06 ms** | **90.43 tokens/s** |

## 3. 多并发极限吞吐测试 (Concurrency & Throughput)

固定输入 512 Tokens，输出 256 Tokens（典型智能体任务抽取负载），测试不同并发压力下的吞吐提升与显存饱和度。

| 并发序列数 (Concurrency) | 生成 Token 总数 | 批次总耗时 (s) | **生成吞吐 (Output Tokens/s)** | **系统总吞吐 (Total Tokens/s)** | 显存占用 (MB) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **4** | 1024 | 3.2164 s | **318.36** | **955.09** | 30447.0 |
| **8** | 2048 | 3.2858 s | **623.28** | **1869.85** | 30533.0 |
| **16** | 4096 | 3.8025 s | **1077.2** | **3231.59** | 31607.0 |

| **64** | 16384 | 7.1642 s | **2286.94** | **6860.81** | 31991.0 |

## 4. 关键结论与 HB10 对比建议 (Conclusions & Comparison Guide)

1. **单卡单流首字与解码表现**: 在标准交互场景 (512 in / 256 out) 下，单流生成速率达到 **91.42 tokens/s**，单 Token 解码延迟 (TPOT) 为 **10.94 ms**。
2. **显存 95% 饱和吞吐极限**: 当并发提升至 64 时，32GB 显存几乎完全被 KV Cache 充满，生成吞吐达到峰值 **2286.94 tokens/s**（系统总吞吐达 **6860.81 tokens/s**）。
3. **与 HB10 对比的关键对照基准**:
   - **吞吐量维度**: 对比相同模型 (Qwen-9B/8B 量级) 在 BS=1, 8, 32, 64 时的生成 Tokens/s。
   - **时延维度**: 对比首字延迟 (TTFT) 及每 Token 解码延迟 (TPOT)。
   - **显存与上下文容量**: 对比最大可容纳并发 KV Cache 块数及最长支持的 Context 长度。
