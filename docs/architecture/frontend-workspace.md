# 对话工作台界面

2026-10-19：按已确认的首屏方案优化现有 Flask 静态前端。保留现有 HTML `title`、初始产品标题，以及 `I18N.zh/en.title` 的全部文字。中英文切换沿用原行为。

## 布局与设计决策

- 保留深色、青色与左右双栏。取消全文扫描线与大面积发光，用背景层级、边框、间距区分内容。监控页面和连接凭据弹窗使用同一套视觉方向。
- 首屏展示知识查询、任务创建两个入口。示例只填入输入框，不发送请求；发送首条用户消息后收起欢迎区。完整能力说明继续来自 `index.js` 的 `I18N[currentLang].welcomeMsg`，放在可展开的使用说明中。
- 侧栏按任务状态展示工作单；没有任务时隐藏空字段、警告与发送卡。模拟时间置顶、加粗，其设置折叠。手机端工作单默认折叠，支持键盘展开；对话区保持输入框可见。
- 工作单分别统计已确认、待核对与待补充字段，显示字段来源及本轮变化。任务名称下呈现当前待办和定位入口，参数按设备、作业、时间等类别分组。待确认时，关键参数直接展示，其余参数可展开查看；确认摘要随工作单滚动，字段可点击定位。
- 对话顶部的可展开回执展示最终快照中的参数、校验状态、校验时间和所用设备状态信息。历史恢复明确标为恢复状态，不生成模型思考过程或工具调用时间线。
- 输入框支持多行与自动增高。保留中文输入法组合期间不提交、Enter 发送、Shift+Enter 换行的规则。语音增加计时、取消和纠正对比；取消转写后，迟到响应不得填入或发送。
- 进度与操作来自实际请求及后端状态。页面不以动画暗示机器人已连接，不生成假进度、置信度或遥测。

### 元素精修

- 操作图标使用本地 `frontend/icons/` 中统一的 24×24 SVG，通过 16–18px CSS mask 展示，1.5px 圆端描边。图标不进入按钮文案或 Tab 顺序；中英文切换、发送中和录音状态的文字更新不会清除图标。录音图标沿用真实 `.recording` 状态切换停止图标。
- Agent 头像复用现有 SEALIEN 品牌图形，与头部标识保持一致。欢迎区角落使用静态海底等深线，标记为装饰性内容，不表示实时地图或遥测。
- 工作单分区标题、字段值和辅助说明分别采用清晰的字阶；统一卡片圆角与装饰边框，减轻卡片内示例入口以及历史、重置等辅助操作的视觉权重。输入边界和键盘焦点提示继续保留。
- 本轮真实字段变化可短暂高亮一次；`render`、`restore` 等重绘不触发这段动效，减少动态效果偏好关闭动画。模拟时间继续位于侧栏最上方，日期时间保持 20px/700，产品标题文字与字号规则不变。

### 任务核对优化（2026-10-27）

- 当前待办复用最终快照中的任务阶段、字段状态和约束结果；入口只定位相应字段、警告或确认摘要，不发送指令。只读和已结束任务显示对应说明。
- 字段分组仅改变展示顺序，保留原字段内容、候选操作与事件监听。未知字段归入其他参数，来源、风险与本轮变化继续可见。
- 确认摘要只展示有效值，字段值使用 14px 字号；参数较多时优先呈现任务、设备、水深和起止时间，其余参数通过带数量的折叠入口查看。校验状态及已接受风险始终位于折叠区域外。
- 同一任务重绘和语言切换保留摘要展开状态；切换任务和重置清除展开状态。发布按钮沿用已有权限、防重复提交及确认令牌校验。

## 文件职责

- `frontend/index.html`：语义化结构、固定 DOM ID、任务工作单与输入区。
- `frontend/js/index.js`：既有请求、会话、语言、语音、字段与风险流程，调用可选 workspace 展示接口。
- `frontend/js/workspace.js`：首屏卡片、空态、语言标签、进度、输入框高度与滚动行为。作为 `ui_state` 的展示消费者，不另建任务状态源。
- `frontend/js/task-insights.js`：最终快照比较、参数计数、本轮变化、确认摘要、处理回执和字段定位。只保存展示基线，不修改任务或决定发布权限。
- `frontend/css/index.css`：已有 Markdown、候选与载荷等任务组件基础样式。
- `frontend/css/workspace.css`：工作台布局、视觉主题、响应式与无障碍覆盖层。使用本机字体，不依赖外部字体服务。
- `frontend/icons/`：装饰性操作图标，作为静态资源加载，不依赖外部图标库或字体服务。

## 状态与操作边界

- 存在 `ui_state` 时，以 `task_type_key`、任务编号或槽位判断任务上下文。知识问答中的已有槽位继续展示；无任务的知识问答保持空态。
- 发布入口仅在确认阶段展示。事件处理再次核对最新 `can_publish`、`can_confirm`、`can_send`、只读状态和在途锁，发送明确的“确认发布”。不根据字段数量推断发布许可。
- `done` 显示“已归档”。下发与执行状态独立；计划任务明确提示到期后手动检查并下发。
- 风险卡使用业务 `phase` 区分软硬约束，流程进度仍使用 `workflow_phase`。风险接受与发布分开。旧风险卡在状态更新时转为只读历史结果，旧处理器不能作用于新状态。
- 断流后的“核对当前状态”只读取会话状态，不自动重发原指令。用户阅读历史消息时，新回复不强制滚动到底部。
- `updateSidebar(data, {origin})` 明确区分 `reply`、`render`、`restore`、`refresh`。仅回复快照计算本轮变化；语言重绘保留变化，恢复/刷新建立新基线，重置清除基线。会话、会话代次、任务类型、正式编号变化及终态切回草稿时，不跨任务比较旧值。
- 语义比较关注值、候选值、状态，以及无效/未解析字段的原始输入。来源、置信度或版本号单独变化不冒充参数修改。确认摘要仅使用 `valid` 字段，冲突保留值和候选值分别展示。数字 `0`、布尔值和结构化值不因真假值判断而丢失。
- 校验证据直接使用 `observed_value`、`threshold`、`source`、`validated_at` 和规则关联字段；不从提示文案猜测单位、比较符或阈值。`pending_runtime_validation` 明确显示等待运行条件校验，过期结果不得显示校验通过。
- 字段引用只滚动并聚焦对应行；风险卡的修改入口只填写输入草稿。来源标签、字段与证据使用文本节点，保留已有 Markdown 消息净化流程。状态异常时隐藏旧摘要并禁用发布。

## 监控页

- 范围明确为当前网关的全部 ROS 任务，不推断不存在的机器人范围筛选。
- 服务端最近接收遥测时间与浏览器最近成功拉取时间分开显示，带时区。状态请求失败保留已有快照，明确提示不能代表当前状态；失败不更新成功时间。
- 原 `READY/ONGOING/FINISH` 映射的固定百分比不再显示为实测进度。任务表分别显示发送记录和执行反馈；待确认删除与未知反馈不标为完成。
- 监控移动端表格保留完整列，可通过键盘横向滚动；原有身份、路由和操作权限保持不变。


## 公开设计参考

- [Carbon：空态设计](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)：说明内容为何为空、下一步如何开始，并减少重复空态。
- [NN/g：系统状态可见性](https://www.nngroup.com/articles/visibility-system-status/)：让操作反馈与当前状态清晰可见。
- [W3C：文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[最小点击区域](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：用于检查文字可读性、按钮与键盘交互。
