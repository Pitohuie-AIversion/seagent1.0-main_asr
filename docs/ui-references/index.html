Foxglove · 机器人数据与 Agent

官方 Agent sidebar 文档空态截图：左侧导航、中央数据接入、右侧 Agent。尚未加载机器人数据，截图拍摄日期未确认。

可以借鉴

重点：业务对象与对话

Palantir AIP · Chatbot Studio / Workshop

官方 Workshop 示例应用：资料列表、视频内容、带来源的问答。示例图仍出现 Agent 字样。

左侧选择资料，中部查看内容，右侧进行问答；回答附来源编号与时间位置。

可以借鉴
设备能力、任务参数与问答保持关联；给水深限制、设备能力等结论提供可展开来源，减少来回翻聊天。

重点：深色监控与多机状态

Formant · 机器人群运营

官方设备组示例：两台机器人的数值、曲线、视频及日志同屏；截图内日期为 2025-01-23。

顶部明确设备组与当前视图，底部统一时间轴、回放控制和 LIVE 标识。蓝灰面板配青色强调，数值与图表层级明确。

可以借鉴
用于运行监控页：标明当前机器人范围、遥测更新时间和实时／历史模式；异常项直接进入相应设备详情。

04

重点：人工核对与确认

Dify · Human Input

2026 年官方发布文章的配置与 Test Run 表单预览合图，属于工作流构建和测试界面。

核对内容、评论输入框和 Confirm／Regenerate／Forward 操作放在同一表单；每个动作指向不同的后续分支。

可以借鉴
把现有发布确认组织成清晰的任务摘要、约束结果与修改意见；操作按钮直接表达确认发布或返回修改。

行业：水下机器人作业

Greensea IQ · Bayonet Workspace

官方产品页中的操作终端屏幕实拍，保留原图；不是平面截屏。

地图、视频、声呐、姿态和控制信息共处作业界面。设备、传感器与任务工具有明确分区。

06

行业：海洋数据与空间上下文

Kongsberg · Blue Insight / Geomatics

官方 OceanView 示例：左侧图层、中央海洋空间数据、右侧对象属性。示例数据日期不代表当前版本日期。

地图占据主要空间，图层控制和选中对象详情分置两侧；传感器仪表盘将即时数值与趋势配对。

可以借鉴
后续把作业位置、管线和环境图层关联到任务，并允许从对象进入对应测量记录；环境指标同时标出单位与采集时间。
