## 2026-11-04 - Missing Authentication on Web Backend API Endpoints\n**Vulnerability:** Found multiple sensitive web API endpoints (`/api/session/state`, `/api/telemetry`, and `/api/history/list`) missing the `@_require_api_token` decorator, potentially exposing session history and ROS2 telemetry data.\n**Learning:** In a Flask application constructed from multiple decoupled blueprints, security decorators must be manually applied to every newly added route. Relying on an incomplete list of secured endpoints creates significant security gaps over time.\n**Prevention:** Apply the `@_require_api_token` decorator systematically to all sensitive internal API endpoints in the backend blueprints, or consider wrapping sensitive Blueprint groups globally if the framework supports it.
