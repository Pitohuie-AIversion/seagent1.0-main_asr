## 2024-11-01 - [Missing Authentication on API Endpoints]
**Vulnerability:** Found multiple `/api/` endpoints (like `get_telemetry_snapshot`, `get_session_state`, `get_current_time`, and `api_history_list`) missing the `@_require_api_token` decorator, exposing sensitive app state and telemetry to unauthenticated users.
**Learning:** This codebase uses Flask Blueprints but relies on endpoint-specific decorators (`@_require_api_token` from `src.web.state`) for authentication instead of applying it at the Blueprint or middleware level. This pattern requires developers to remember to explicitly protect every new endpoint, making it prone to human error and oversight.
**Prevention:** Future API endpoint additions must explicitly include the `@_require_api_token` decorator. Consider implementing a fail-safe check during route registration or moving to a global middleware/before_request hook that enforces authentication by default for all paths under `/api/` (except a whitelist if necessary).
